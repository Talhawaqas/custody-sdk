Important: these calls only work if pointed at an origin where the actual /api/* routes are deployed (your Next.js app, not this static harness). If that origin doesn't explicitly allow cross-origin requests, the browser will block this with a CORS error — which is itself a real, useful result: it means a separate third-party frontend would need the backend to send Access-Control-Allow-Origin headers before it could call these routes from a different domain. Calling from code that already runs on the same origin as the API (the normal case) has no such issue.
